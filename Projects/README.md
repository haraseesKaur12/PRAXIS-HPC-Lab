# PRAXIS – HPC Laboratory Projects

This folder contains the project materials developed for the CS565 High Performance Computing Laboratory course at IIT Ropar.

## Project 1: MPI Simulation Using Two Modeling Frameworks

Students explore MPI communication-performance modeling using SimGrid (SMPI) and LogGOPSim.

The project covers MPI execution, communication-parameter measurement, simulator configuration, trace collection, and performance prediction.

## Project 2: Simulation–Execution Gap Analysis and Optimization

Students compare measured MPI execution times with predictions from SimGrid and LogGOPSim.

The project focuses on identifying simulation–execution discrepancies, examining modeling assumptions, and exploring approaches to improve prediction accuracy.

## Experimental Platforms

- C-DAC production HPC cluster
